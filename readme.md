## 📚 Mini Conceptos de los Temas

### 🌐 1. HTML (HyperText Markup Language)
Es el lenguaje de marcado estándar utilizado para estructurar y organizar el contenido de una página web mediante etiquetas (`<header>`, `<section>`, `<div>`, `<form>`, etc.). Constituye el esqueleto de cualquier aplicación web.

### 🎨 2. CSS (Cascading Style Sheets)
Es el lenguaje encargado de definir el diseño visual, la presentación y el formato de los documentos HTML. Permite aplicar estilos (colores, tipografías, maquetación con Flexbox o Grid) y crear interfaces adaptables (*responsive design*).

### ⚡ 3. JavaScript (JS)
Es el lenguaje de programación interpretado y dinamico que otorga interactividad a las páginas web. Permite manipular el DOM, manejar eventos de usuario, realizar peticiones asíncronas (`fetch`, `async/await`) y ejecutar lógica tanto en el cliente como en el servidor.

### 🛡️ 4. TypeScript (TS)
Es un superset de JavaScript desarrollado por Microsoft que añade **tipado estático** y características avanzadas de Programación Orientada a Objetos. Ayuda a prevenir errores en tiempo de compilación, facilita el refactorizado y mejora la autocompletación en los editores.

### 🦁 5. NestJS
Un framework de Node.js progresivo diseñado para construir aplicaciones backend del lado del servidor eficientes, escalables y mantenibles. Utiliza TypeScript por defecto y se basa en una arquitectura modular orientada a objetos (inspirada en Angular), haciendo uso intensivo de decoradores, inyección de dependencias y controladores.

### ⚛️ 6. ReactJS
Una biblioteca (library) de JavaScript desarrollada por Meta para construir interfaces de usuario interactivas y reactivas basadas en **componentes reutilizables**. Utiliza un DOM Virtual (*Virtual DOM*) para optimizar el rendimiento y Hooks para gestionar el estado y el ciclo de vida de la aplicación.
